# WebDAV 手动快照备份

Apple 设备的自动接续使用独立的 [iCloud 同步](icloud-sync.md)，不改变以下 WebDAV 手动快照契约。

WebDAV 只提供“立即备份”和“选择时间点恢复”。不会在启动、阅读、导入书籍或修改设置时自动访问云端，也不再提供同步频率、同步范围、冲突合并、单书传输或远端阅读接续。

## 内容与恢复方式

每次创建独立 ZIP。可分别选择书架/阅读进度/书签笔记、阅读统计、书源、阅读设置。书架数据包含全部子书架、嵌套关系和书籍归属，包括空子书架。正文默认不选，点击“备份内容 → 选择书籍正文”按书名搜索、逐本勾选或全选当前列表；显示单本大小、已选本数及压缩前总量。选书只决定正文文件范围；书架元数据仍包含全部书籍和子书架。正文选择包含对应封面和书源章节信息，在线书籍不下载正文。选正文时一并保留书架与阅读数据。

备份页面显示准备、打包、校验、上传、完成确认阶段；打包按读取校验和写入 ZIP 的工作量显示进度，上传/下载显示传输字节、百分比和按时间采样的网速。校验/恢复等不能可靠估算的阶段显示不定进度，切换阶段清除旧网速。断线或失败后恢复按钮状态。

恢复弹窗可分别选择书架/进度/笔记、正文/封面、统计、书源及设置，并选择是否覆盖。默认不覆盖：保留匹配书籍及其进度笔记，添加缺少的书籍和设置；已有统计或书源/书源分组时跳过该类别。开启覆盖后，新格式只恢复所选类别：书架按稳定身份更新对应书籍并重映射书签/笔记外键，保留额外的本地书籍。未备份正文时保留当前设备对应书籍文件；新设备没有正文时仅还原书架数据，需要重新导入书籍。统计、书源和设置各自按选中类别替换，未选类别保留。旧格式 v1 也遵守页面选择；旧版内部完整恢复入口仍保留兼容。界面显示恢复确认，完成后重新载入应用。正文写入新的受管子目录，原文件不直接覆盖或删除。选中的正文缺失会导致备份失败；未选正文缺失不影响数据备份。

选中书架类别时，先恢复父子书架，再恢复书籍归属。子书架按 UUID 匹配，同名但不同 UUID 的目录分别保留；默认保留已有目录的名称和位置，添加缺少的目录，开启覆盖后更新匹配目录，额外的本地目录及其书籍仍保留。不选书架类别时不改动子书架。旧快照没有归属字段时，选择性覆盖保留已有书籍的本地归属，新添书籍进入根书架；新快照明确记录空归属时，覆盖后书籍回到根书架。旧版内部完整恢复旧快照会得到根书架书籍和空目录表。

设备登录、会员状态、WebDAV 密码、AI 凭据与设备权限不随备份恢复。自定义字体文件、自定义背景图片文件、可重建缓存和 TXT 编辑历史不包含在 ZIP 中。主题配置仍可备份，背景图在原设备文件保留时可继续读取；跨设备需重新选择图片，见 [阅读背景图](reader-backgrounds.md)。

备份没有端到端加密，书源配置可能包含用户自行填入的访问参数。WebDAV 密码继续仅保存在系统安全存储中。

## 云端格式

目录为配置目录下的 `backups/`。文件名：

```
origo-x-<UTC 毫秒时间戳>-<UUID>.zip
origo-x-<UTC 毫秒时间戳>-<UUID>.zip.complete
```

ZIP 内包含 `backup.json`、`books/`、`covers/`。`.complete` 是上传完成标记，内容为 ZIP 的 SHA-256；只有存在标记的 ZIP 会显示在恢复列表。中途断线、进程结束留下的未完成 ZIP 不会被当成备份。使用基本 MKCOL、PROPFIND、PUT、GET，连接探测的清理使用 DELETE；不依赖 OPTIONS、MOVE、强 ETag、条件写或服务器锁。

恢复先验证整个 ZIP 的 SHA-256、格式/数据库版本、每个文件的散列、路径及数据结构；路径越界、符号链接、未知文件和不完整备份被拒绝。子书架校验包括唯一 UUID、名称、父目录和书籍引用，以及目录循环；事务内还会检查恢复后保留与导入目录组成的完整层级。ZIP 的 SQL 永不执行。按类别快照使用格式版本 2，同时兼容 v1 完整快照；数据库 schema 28 包含子书架，也接受已知旧 schema 25、26、27 的 v1/v2 快照，缺少的旧目录表按空表处理，未知及未来 schema 被拒绝。每个解压文件最多 2 GiB，总计最多 8 GiB，清单最多 64 MiB。ZIP 写入与解压在独立 isolate 中执行。正文使用 STORE 快速写入，减少重压缩开销（纯文本 ZIP 可能更大）；流式读取计算散列并更新进度，检查读写期间源文件大小和修改时间。不再在上传前全量解压一次；恢复仍验证 ZIP 及每个文件的散列。读取数据库时直接排除正文和分页缓存。

恢复前在应用 Documents 的 `backups/before-restore-<UUID>.zip` 留存不含正文的本地数据安全副本，避免再次打包数 GB 书库；原正文仍留在磁盘。数据库使用事务；设置与书源使用一个本地恢复日志，进程中断后按 SQLite 提交结果补齐或回退。启动时先处理此日志，再载入设置和书源。恢复需要为下载、校验、暂存和本地安全副本预留磁盘空间。

## 升级与代码清理

保留已有 WebDAV 地址、用户名及安全存储密码。忽略旧自动同步配置；不迁移或删除服务器上的旧同步目录，它们不是新格式 ZIP。旧的调度器、同步引擎、数据集适配器、可变 TXT 同步、版本/冲突协议以及同步二级页面已删除。旧同步行为的测试随功能退役，替换为备份往返、损坏输入、恢复回滚、真实 HTTP WebDAV 与页面操作测试；保留传输安全、密码存储及本地书籍身份测试。

`book_sync_identity.dart` 暂保留供本地 TXT 编辑和书源章节更新使用，不执行联网。历史数据库迁移保留，避免破坏升级和已有本地书籍身份。

验证入口：`python3 tool/test_webdav_isolated.py`，各套件在独立 Flutter 进程运行。

- 保留的 WebDAV 传输、安全存储和迁移测试独立进程通过；设置、导入、书籍身份、追更页面及阅读进度的针对性回归通过。阅读进度使用 CI 已有的逐用例隔离方式，未使用会挂起的合并执行结果判断产品。
- 备份相关文件静态分析无问题；Android debug Product build 成功。未做真机、商业 WebDAV 服务或双设备实测。

性能检查：本机 8 MiB 正文快速打包耗时约 125 ms（不含上传，不代表手机速度）；验证中间进度、缓存排除及恢复选项。
