# 阅读净化规则对齐

参照 `/Users/xiaoyuan/code/legado-with-MD3` 当前规则净化实现，复用 Origo X 的
`ReplaceRuleService`、可终止的正则 worker、规则设置页及两个阅读器。

## 行为合同

- 普通文字和正则规则按保存顺序执行；正文允许完全删除，章节标题逐条保留非空结果。
- 标题、正文、书名、书源 URL、书源名称、排除范围和启用状态共同决定是否执行。
- 同一 worker 先处理标题再处理正文、切换书籍时，不能复用错误的规则子集。
- 每条规则保存和执行自己的超时时间；超时隔离规则后继续执行可用规则。
- 全局默认与本书覆盖分别持久化，图片和 EPUB 默认关闭；显式本书选择优先。
- 阅读中保存、删除、排序、启停规则或修改本书开关后，从原始内容重新净化，
  重建标题与正文缓存，保留章节和阅读位置，拒绝旧异步结果覆盖新版本。
- 阅读页可进入本书规则管理、查看实际改变当前正文的规则，并从选中文字建立本书文字规则。
- 管理页复用现有存储和编辑器，支持分组筛选、批量启停/删除/导出、复制粘贴及顺序调整。
- 新规则至少作用于标题或正文；已有异常记录不应阻止其余规则加载。

## 兼容边界

常用 Java 捕获组、替换转义和水平空白语义通过已有 Dart 规则适配器实现。
完整 JVM/Rhino API 不能等同于 Dart/JavaScript API。现有 Apple JavaScriptCore 运行时
没有公开的可终止执行边界；不得将 `@js:` 当作正文替换文本，也不得引入不能终止的脚本执行。
此类规则应保留可编辑记录，并明确显示不支持的原因。

## 验证

规则服务/worker 使用针对性测试，两个阅读器与编辑器的 stateful widget 测试分别启动独立进程。
静态分析和 `git diff --check` 覆盖本次改动；保留既有未提交改动。

## 本地交付结果

- 规则核心复用原有服务、存储及 worker，修复跨目标、跨书籍与签名淘汰后恢复旧配置的漏执行。
- 超时规则按当前内容指纹持久停用；历史异常记录保留为禁用记录，可继续编辑。
- 管理页新增全局/本书开关、分组和批量操作、JSON 复制粘贴、置顶置底、超时字段和实际生效提示。
- 本地与在线阅读器共用书架本书标识；从原始内容重新净化，按文字锚点恢复位置。
- 连续更新、首次标题加载、正文请求未结束及搜索临时章节均传递完整上下文并拒绝过期结果。
- 选文工具栏复用共享编辑器，创建本书普通文字删除规则；新增文案覆盖现有 10 种语言。

规则服务、执行器、书源文本替换及管理页四组回归通过；管理页最终 10 项、共享选文组件最终
13 项通过。阅读器 14 项 widget 用例分别在独立进程验证，定位 4 项单测通过，依赖注入检查通过。
`git diff --check` 通过。完整静态分析没有 error 或 warning，另有 3 条 info 位于本轮未修改的
`source_chapter_state.dart`、`source_cookie_utils.dart`、`offline_reader_license_refresh_test.dart`。

原生环境支持隔离执行正则。Web 沿用已有文字替换能力，不能终止的正则不会在 UI 线程执行。
Rhino `@js:` 替换、完整 JVM 专有正则语法仍属于兼容边界；不支持的脚本会明确提示。
