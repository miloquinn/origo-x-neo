# 书架分组与排序设计

状态：**Draft，待用户审核，未实施**。日期：2026-10-05。

## 需求与边界

用户提供的反馈是：「希望书架弄一个分组功能和排序功能，排序功能可以按照最近阅读、添加时间等等对书籍排序」。本阶段调查、设计并提交审核，不修改应用代码，不提交或发布。

目标是让本地书、在线书、PDF 和漫画在同一个书架中方便归类、找书、续读。首期提供自建分组、单本与批量移动、三种排序及方向记忆，沿用当前阅读状态筛选、搜索、布局和书籍操作。

首期不增加嵌套文件夹、一本书多组、书籍拖拽排位、置顶、自动分类、分组颜色或图标配置。分组随现有 WebDAV **备份恢复**保存，不承诺实时跨设备同步。

## 推荐界面

推荐 **「分组下拉 + 当前排序摘要」一行**，放现有顶栏下、书籍集合上方：

```text
书架                       搜索 下载 筛选 添加

全部书籍 ⌄  24 本                  添加时间 ↓

[既有封面网格／卡片列表]
```

左侧点开分组选择器；右侧摘要与顶栏筛选打开同一份「书架显示」菜单。摘要只表达方式与方向，不新增排序页面或第五个常驻图标。

备选为横滑栏「全部／未分组／小说／学习…」：少量分组可以一键切换，但多组与长组名占空间。两者功能、数据相同；预览提供两种入口，推荐下拉。

沿用现有 12／16px 手机边距、两列／三列封面、平板与桌面自适应列数。列表与网格共用可见结果，不在每张卡片再放分组徽章。组名在摘要中省略，选择器显示完整名称。浅／深色、Material 3／玻璃风格复用现有主题、共享锚定菜单与弹层。

手机／平板必须计算现有 shell 顶部安全区与悬浮工具栏 inset，分组行不能藏在顶栏背后。打开搜索时顺序为「顶栏 → 搜索条 → 分组与排序行 → 书籍」；列表顶端留白与内容区域同步调整。桌面内部顶栏下面采用同样顺序，不再叠加手机 inset。

## 分组规则

- 一个书籍记录最多属于一个自建组；没有归属时在「未分组」。
- 「全部书籍」是汇总视图，「未分组」是筛选视图，二者不作为真实组保存。
- 新导入和在线新加书默认未分组，不因当前浏览组不同而自动归类。
- 在读／已读仍是阅读状态筛选，与用户分组独立，不自动搬动书籍。
- 分组与书源分组独立；刷新来源、换源、下载成本地书、编辑封面或书名都保留原归属。

### 选择分组

选择器排列「全部书籍、未分组、自建组」，显示各组总书数；计数不随搜索与状态筛选变化。支持搜索组名，底部提供新建和管理。很多分组时列表滚动，不挤出操作。

切换组保留搜索词、状态与排序，书籍区域回顶部；摘要本数表示组合条件下的结果数。本机记住最后浏览组，首次使用默认全部；记住的组不存在时回全部。搜索与多选不跨重启保存。

分清空组与筛选无结果：空组提示「这个分组还没有书」；筛选无结果提示「没有符合当前筛选的书」，提供清除搜索与状态。整体空书架保留现有导入／发现入口。

### 单本与批量移动

长按既有书籍弹层新增「移入分组」，显示当前归属。选择目标即保存，可移回未分组，也可当场新建后移入。数据库成功后再关闭与反馈；失败保留弹层和原归属。

单本移出当前组后从列表消失，提示「已移入『小说』」并提供撤销。撤销恢复原归属，原组已不存在时回未分组并说明。书仍可见时保持身份与合理滚动位置。

沿用「选择多本」和全选，底部增加「移入分组」，与既有删除并列。移动为普通主操作，删除保留危险样式与确认。零选中时禁用两项。全选只作用于当前分组 × 状态 × 搜索结果。

批量移动一次事务全成或全败；成功退出多选，反馈数量并允许撤销至各书原归属。多选时锁住分组、排序、状态和搜索，先退出再修改视图；外部刷新仅保留仍存在且可见的选择，不扩大范围。

批量撤销逐书校验原组：仍存在则恢复，否则回未分组；已删除的书跳过，不重建书籍。对仍存在的书在一个事务中提交，成功提示恢复数量及回未分组的降级数量；数据库写入失败时全部回滚，保留撤销入口。不要为了其中一个原组消失而阻止其他书恢复。

### 管理分组

- 新建、改名、调整组序、删除；组序只影响组列表，不影响组内书序。
- 名称去前后空格，1–20 个可见字符；同机重名不允许，英文不区分大小写。「全部书籍／未分组」及当前语言系统名称保留。
- 改名只改名称，稳定 ID 保持书籍关联；长名和大字号允许换行。
- 管理页拖动调整组序，补充键盘与屏幕阅读器可用的上移／下移；不做书籍拖拽排序。
- 删除确认：「删除『小说』？该组的 12 本书将移到未分组，书籍、阅读进度和缓存都会保留。」
- 空组可删除；删除书籍不自动删除空组。删除分组和清空书架是独立操作。

## 排序合同

| 方式 | 默认方向 | 来源与规则 |
| --- | --- | --- |
| 添加时间 | 新 → 旧 | 现有 `importDate`，本地导入／在线首次加书时间；刷新、下载、换源不重设。首次升级保持当前顺序。 |
| 最近阅读 | 新 → 旧 | 新增 `last_read_at`，成功打开可阅读内容／成功开始该书听书时记录。没有真实时间的书始终置后，再按添加时间新→旧。 |
| 书名 | 升序 | 去前后空格、英文大小写折叠后的原文字符顺序；首期不引入拼音或自然数字排序依赖。 |

每种方式可反向；时间方向文案为新→旧／旧→新，书名为升序／降序。方向只反转主键；同值按添加时间新→旧、书籍 ID 稳定排列，未知最近阅读在双方向都置后。

排序是全书架共享的本机偏好，各组共用。方式与各方式最近使用方向持久化；首次切入未使用方式采用默认方向。备份选择设置时保存此偏好。

共享「书架显示」菜单保留状态区，新增排序方式、方向区，当前项勾选。组、状态或排序偏离默认时顶栏按钮激活。一键「恢复默认显示」回全部组／全部状态／添加时间新→旧并清空搜索。

### 最近阅读时间

定义为最近一次**成功打开阅读内容**，不要求翻页、进度大于零或累计时长。新增书籍级时间，不每次从统计推算。

- 文本、EPUB、在线、PDF、漫画在每个新阅读 route 的首次内容可消费后调用同一方法并标记已记录；章节切换、分页、重排、widget 重建均不重复写入。不可把初始化时 `markReading` 当成成功。
- 书架、首页续读及其他入口采用同一规则；进程恢复创建的新 route 在内容成功可用后记一次，从后台回到原 route 不更新。只恢复数据库位置／快照而没有打开可消费内容不更新。
- 听书每个新书籍播放会话首次真实进入 playing 后记一次；暂停续播、每句播放、预取与无声失败不重复。换书或结束后重新启动构成新会话，实施时沿真实播放器状态验证接入点。
- 未入架试读不写入；成功阅读中加入书架时给新记录补当前真实时间。
- 加书、改名、换源、下载、缓存、统计清除和恢复阅读位置不模拟阅读时间；清统计不清 `last_read_at`。
- 返回书架按当前方式刷新，转场仍使用书籍 ID。记录失败不阻止阅读，保留旧值并记录诊断。
- 迁移只从真实会话最大结束时间回填。无历史证据的 PDF／漫画等留空，下次成功阅读后记录；不拿页码、文件修改时间或迁移时间猜测。

## 数据设计与实现约束

复用既有 SQLite 与 UUID 依赖，不新增依赖：

| 位置 | 新增内容 | 用途 |
| --- | --- | --- |
| `shelf_groups` | `id TEXT PRIMARY KEY`、`name TEXT NOT NULL`、`sort_index INTEGER NOT NULL` | 稳定 UUID，支持改名、空组与组序。 |
| `books` | `shelf_group_id TEXT NULL`、`last_read_at INTEGER NULL` | 单书单组，毫秒时间与现有添加时间一致。 |
| 本机设置 | 排序方式、各方向、上次浏览组 ID | 显示偏好与书籍业务数据分离。 |

`books.shelf_group_id` 为可空外键 `REFERENCES shelf_groups(id) ON DELETE SET NULL`。当前数据库已开启外键检查，迁移先建组表再添加可空列；新建库也保持该顺序。删除组和归属回退同一事务，除 SQL 外键外，DAO 和归档验证还要约束 UUID 格式、去空格后的名称唯一、合法长度，以及非负整数组序；组序变更在事务中归一化。同一次归档中重复组序拒绝，恢复与本机组合后的序号按合同重新生成，不依赖数据库返回顺序。

现行数据库版本 27，实施时以最新迁移号为准追加一次迁移，兼顾新建库。旧归属为空，回填真实时间；不重建书籍身份，不清定位、书签、笔记与缓存。

分组写入、批量移动及撤销用小范围 DAO 事务，复用 `LibraryEventBus`，不新建全局状态体系。模型序列化、`copyWith`、轻量书架投影与针对性更新保留新字段，防止阅读写回、换源、下载把旧模型空值覆盖到归属。

可空字段更新必须区分「未修改」和「主动设为空」：采用现有可空字段更新模式或 sentinel 参数，DAO 提供显式移回未分组／清时间的操作，不能用 `newValue ?? oldValue` 实现主动清空。通常阅读进度和来源更新仅改各自字段，避免整对象写回覆盖分组。

公共集合执行「分组 → 状态 → 搜索 → 排序」。扩展现有单结果 memoization 条件，加入组、方式、方向；归属或阅读时间变化推进原有版本，不建新缓存体系。一次批量加载，不逐封面查询，不载正文排序。时间只在成功进入／开始听书时写入，不每翻页写库。

## WebDAV 备份兼容

以 `docs/webdav-backup.md` 和 `BackupArchive` 为准，不引入历史双向同步协议。

新增表进入归档，建议备份格式由现有 v1/v2 升为 v3。旧 schema 不能通过简单删除校验放行：对支持的版本先验证、归一化，再映射到当前格式。至少覆盖 schema 27 的 v1/v2；更早 schema 实施时核实原支持范围，不无依据承诺全部兼容。

- 完整书籍信息／阅读数据备份包含组目录、组序、空组、归属与阅读时间，不依赖设置选择。
- 现有「选择书籍」只决定正文／封面文件，不是选择部分书架元数据。勾选书架／阅读数据，或选择任一正文从而启用该范围时，始终归档完整组目录和全部书籍归属；仅设置备份不带分组业务数据。首期不新增局部书架元数据备份／恢复 UI。
- 设置另外携带排序偏好，恢复后不存在的最后浏览组回全部。
- 分组先于书籍恢复、删除顺序相反；选择性恢复沿用稳定书 UID 合并及整数 ID 重映射。
- 沿用当前按类别恢复及「是否覆盖」合同，见下表。不把最近阅读强行取较新值，否则无法按时间点回滚。当前用户页面保留额外本机书籍，不设计新的完整替换入口；旧内部完整恢复路径只保持兼容。
- 同名不同 UUID 不默默合并；要应用的归档组名冲突时，命名为「名称（恢复）」并按需加序号，生成名遵守长度与重名约束。归档先验证内部合法，再在恢复事务中处理与本机冲突。
- 引用不存在组、重复 UUID、非法名称等在恢复提交前拒绝，不静默丢分类。
- 旧版应用可能拒绝新归档；新版恢复受支持旧归档是发布门槛，不宣称双向降级兼容。

| 恢复条件 | 书籍归属／最近阅读 | 分组目录与组序 |
| --- | --- | --- |
| 未选择书架／阅读数据 | 全部保持本机 | 全部保持本机 |
| v3，不覆盖，已匹配本机书 | 保持本机，含本机空值 | 同 UUID 保持本机名称与顺序；缺少的归档组按归档顺序追加 |
| v3，不覆盖，新书 | 按快照建立，显式空值按空值 | 先建立需要的归档组，含归档空组 |
| v3，覆盖，已匹配或新书 | 按快照写入，含显式空归属／空时间 | 同 UUID 采用归档名称；归档组按快照顺序，额外本机组保留并按原相对顺序追加 |
| v1/v2 缺少新字段，已有书，任一覆盖选择 | 这两个字段保留本机；旧格式无法表达主动清空 | 保留本机组，不清目录 |
| v1/v2 缺少新字段，新书 | 未分组；时间仅从归档真实会话回填，无证据留空 | 不凭书名创建组 |
| 任一版本，本机额外书籍 | 保留 | 其引用的本机组不能丢失 |

开启覆盖的 v3 时间回滚以后，下次真实打开阅读或开始听书才更新为新的当前时间。恢复动作自身不制造阅读事件。

## 状态、响应式与可访问性

加载沿用现有状态，切组／排序不请求网络。保存中禁重复提交，失败保留原数据与草稿。手机弹层受安全区和键盘约束，宽屏限制弹层最大宽度；两套顶栏功能一致。

目标至少 44×44；名称、书数、方向、选中状态有语义。支持鼠标、键盘、触屏，Escape／返回关闭，Tab 有稳定顺序，关闭后焦点回触发器。320px、横屏、1.3／1.5 倍字号、长译文与长组名不遮操作。减少动态效果遵循现有设置，成功与失败不只用颜色表达。

## 实施顺序与验收

审核确认后再实施：①数据库、DAO、时间与模型保留；②备份 v3 和旧归档兼容；③公共筛选排序、偏好、分组与移动、两套顶栏；④全格式／听书成功链路、真实 Flutter 视觉和真机验收。

| 层 | 必须证明 |
