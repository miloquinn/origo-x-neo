# 用户书源通用兼容收敛计划

## 范围

以 `/Users/xiaoyuan/work/书资源/书源_519个.json` 和
`/Users/xiaoyuan/work/书资源/shareBookSource(2).json` 为只读语料，修复
Origo X 与 Legado 之间已经由实际样本和运行诊断确认的共享契约差异。
不按域名增加规则分支，不把源文件复制进仓库，也不把站点失效、登录、验证码或
原生 WebView 结果伪装成解析成功。

## 行为锁定

1. 公开来源在安全存储插件不可用时仍能完成网络请求和规则解析；明确登录保存仍报告
   持久化失败。
2. 脚本宿主保留现有网络/交互边界，并提供已核实的通用 Legado 浏览器展示别名；测试
   请求方法、参数和返回值形状，不测试某个域名。语料中的能力探测 API 保持未定义，
   避免改变来源自己的 try/catch 分支。
3. 两个用户来源触发的代表性共享边界（请求头片段、响应头重定向、正文 DOM 和浏览器
   展示）使用合成响应验证，避免把在线站点状态混入引擎回归。

## 清理顺序

1. 先补最小失败回归，确认失败来自会话持久化和宿主 API，而非规则本身。
2. 修复 `SourceRuntimeSessionManager` 的可选存储边界和脚本宿主唯一入口。
3. 删除不再需要的错误传播或重复适配；不新增第二套规则解析器。
4. 运行相关 source/config/script/runtime 测试、格式检查和静态分析。

## 回退分类

- 安全存储缺失时保留内存会话是平台能力边界上的有界 fail-safe；登录显式写入仍失败，
  不吞掉真实存储损坏。
- 浏览器展示 API 只在脚本宿主边界提供一次；不为单个来源改写脚本。`base64Decoder`
  等来源能力探测 API 不伪造实现，保持其原本的异常探测语义。
- 源文件中的空返回脚本、错误 WebView 参数和在线站点拒绝访问属于来源或环境问题，
  不用默认值恢复。

## 验收

- 代表性规则脚本回归通过；安全存储插件缺失的公开读取回归通过。
- `flutter analyze --no-pub`、相关 `flutter test --no-pub --concurrency=1` 和
  `git diff --check` 通过。
- 报告两个文件的结构统计、在线诊断结果和仍未验证的原生 WebView/真实站点边界。
