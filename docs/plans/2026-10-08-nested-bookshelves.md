# 嵌套子书架

Status: Active，2026-10-08 用户授权设计并实施。替代 2026-10-05 的分组下拉草案。

## 交互合同

- 根目录展示直属书籍和文件夹；一本书只属于一个目录，移入后不在父目录重复展示。
- 多选当前目录的书籍 →「新建分组」→ 输入名称 → 在当前目录创建文件夹并原子移入所选书籍。
- 文件夹和书籍共用当前网格/卡片布局，显示最多九本后代书籍的封面和总书数；不加载正文、不逐书查询。
- 点文件夹在当前书库内进入子书架，左上标题改为目录名。左侧悬浮「返回上一级」；系统返回先退出多选，再返回父目录。每一级保留滚动位置。
- 当前目录提供新建空分组；子书架可以继续嵌套。搜索/阅读状态作用于当前目录直属书籍，文件夹按名称或匹配后代显示，保持可进入的路径。
- 单本及批量书籍可移入已有目录或根目录；文件夹支持改名、移动和解散。禁止移入自身或后代。解散将直属书籍和子目录提升一级，保留文件/进度/笔记。
- 保存期间防重入；名称去除首尾空白，非空且最长 60 字符；失败显示错误并保留原目录与选择。同名目录使用不同 UUID。
- 保留玻璃设置、主题、封面比例、书籍打开动画、导出/删除和手机、平板、桌面布局。

## 数据与备份

- 数据库 v28：`shelf_folders(id TEXT PRIMARY KEY, name, parent_id nullable FK, created_at)`；`books.shelf_folder_id` 可空 FK。索引覆盖目录/书籍归属，事务维护层级和移动。
- Book.copyWith 保留归属并提供显式清空；摘要读取带归属。变化沿用 LibraryEventBus 刷新。
- WebDAV ZIP 快照纳入目录图与归属，兼容旧 v1/v2 无目录字段；恢复先处理目录、再书籍。校验引用、循环和恢复后合并图；选择性覆盖区分缺字段和显式 null，按稳定 UID 重映射书籍。
- 无需服务端改动；不加入实时同步，不顺带实施旧草案的阅读时间排序。
