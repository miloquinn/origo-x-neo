## Open-access paintings

The Met Open Access policy: https://www.metmuseum.org/pt/hubs/open-access
The two object API responses were checked for `isPublicDomain: true` before download. Museum images are released under CC0. They are public-domain artworks, not software licensed as open source.

- Katsushika Hokusai, Under the Wave off Kanagawa, ca. 1830–32. Object 45434: https://www.metmuseum.org/art/collection/search/45434
- Vincent van Gogh, Irises, 1890. Object 436528: https://www.metmuseum.org/art/collection/search/436528

The book cover titles, paper layout, text excerpts, audio ribbon, note and network compositions are original design mockups. They illustrate capabilities and do not claim books/content are supplied by Origo. 'O' is a placeholder monogram, not a replacement for the production app icon. No live account/network state is represented.

## Fonts and scope

Uses system-installed Chinese serif/sans fonts; no font binary is redistributed. All asset files are local. The only outbound links are explicit source attribution links. Prices are USD examples; final production UI must retain store-returned local prices and all existing purchase states.

## Interaction review

Three feature tabs, keyboard left/right navigation, full Basic benefits, Premium details, back/Escape, and preview-only purchase/trial/restore feedback. At 390x844 inner phone size, both main bodies fit without vertical scrolling; long benefits intentionally scroll on their secondary pages. This HTML establishes art direction only; Flutter, device safe areas, localization and accessible font scaling need production validation after this direction is accepted.
