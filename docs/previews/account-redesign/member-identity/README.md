# 已购会员身份卡

- 开卷：跟随强调色的浅金属卡面、书页线纹、开卷徽章。
- 探元：深色金属卡面、浅银色字、探元徽章与藏书印记。
- 已拥有探元不出现购买推广卡；已拥有开卷保留独立探元升级卡。
- 官网免费访问和试用不冒充已购会员；官网账号已购开卷可显示身份。
- 沿用现有十语言会员名称，不引入素材、字体或绘图依赖。
