# 欢迎页：一本书的旅程

状态：2026-09-26 动态概念样稿，等待视觉反馈。

## 依据与范围

现有 `lib/pages/legal/user_agreement_page.dart` 将介绍、条款、书源边界和隐私拆为四步，以 AnimatedSwitcher 做淡入位移。用户希望重新设计，并先试一版连续动效。

本轮新建独立 Flutter 入口 `tool/welcome_preview.dart` 和可复用页面 `lib/pages/onboarding/reading_welcome_page.dart`。正式启动入口、协议内容、确认顺序和存储不变。中文文案为待审样稿；接入正式流程时再纳入现有 l10n。

最新用户反馈：书封应朝读者抬起后向左展开；条款默认收拢，只展示重要内容，用户点开查看全文，一次同意即可。预览将 `AgreementSummary` 放进同一个 PageController 的第四页；完整协议原文继续复用原 l10n。中间版本的独立三步协议接法已撤回。

## 视觉与交互

- 配色：纸白 #F7F7F2、松墨 #253B36、正文灰 #67736C、书封金 #D6C59D、浅叶色 #EAEEE5。
- 排版：左对齐双行大标题，短正文，底部进度和单一主按钮。图画占主要留白，不放功能卡片。
- 核心资产：一本原创几何书封，以山、海、日构成封面图案，Flutter Canvas 直接绘制。
- 品牌标识：左上角和演示结束页直接复用 AppBrandIcon 与 assets/images/app_icon.png（现有蓝粉书本图标），独立预览构建同步打包原资产。
- 0 → 1：书封绕左书脊向读者抬起、从右向左展开；外沿随透视靠近放大。封面和内封使用同一投影，内封文字翻转校正以保持正向。书脊逐渐居中。
- 1 → 2：同一本书合拢、缩小落入书架，旁边两本书逐渐显现。
- PageController 的连续位置直接控制同一幅绘画；拖动可停留和反向，不在页切换后另播动画。
- 按钮导航 850 ms，easeInOutCubic；左右方向键、鼠标拖动和触摸均可导航。
- 减少动态效果时按钮直接跳页，插画切为离散状态；没有自动循环动画。
- 2 → 3：同一幅绘画中的书架淡去，主书缩小并上移到摘要标题上方；过程直接跟随拖动，可逆，不切换到另一个独立法律页面。
- 第四页：使用条款、第三方书源、隐私三个可展开条目，默认全部收拢，展示开源许可、官方不提供书源、本地保存这三个事实摘要；点开后可读全部原文。
- “跳过介绍”只跳到第四页。全文展开不是同意的前置门槛，底部只有“同意并开始阅读”；左右方向键只导航，不触发同意。
- 概念宿主的同意回调进入可重播终点，不写真实协议记录。正式 App 默认流程及同意服务暂不替换，待样稿确认后统一接入。
