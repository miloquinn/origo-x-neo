# 问题反馈与性能摘要

Android/iOS 设置的帮助按钮及「关于与支持 → 问题反馈」进入原生反馈页。登录后提交分类和说明；反馈不自动附带性能摘要。截图、阅读正文、书名、书源地址和日志不在此功能采集范围。

## 采集与用户选择

「帮助改善耗电与性能」默认关闭，设备本地保存选择，不经 WebDAV 备份迁移。首次同意 APP 协议后，待法律网络门开启且诊断控制器初始化成功，APP 在下一帧单独展示一次性说明；协议页先完全退出，首页支持引导延后到该选择完成再显示。用户必须明确选择「暂不开启」或「同意并开启」；两种选择都保存为设备本地决定，不再重复弹出。用户可之后在设置中开关，设置中的主动选择同样成为已决定状态。 本机 `member_diagnostics_consent_choice_v1` 记录明确决定；新状态优先于旧开关标记，旧版已经手动开启的用户保留选择。弹窗等保存成功才关闭；保存失败显示错误并保持当前进程停止采集。

弹窗明示性能与耗电摘要包含 CPU 时间、内存占用、帧性能、热状态、有效前台时段的整机掉电估算、机型、系统版本、APP 版本与构建号。整机掉电估算不等于 APP 独占耗电。不收集书名、阅读正文、书源内容、自由日志或账号凭据，并可直接打开当前隐私政策。用户主动开启且当前协议已接受后，只在前台低频采集；自动摘要登录后才按当前账号批量上传到我们的服务，最长保留 30 天。关闭立即停止采集并清除待上传摘要；切换/退出账号清除旧账号摘要，不能上传到另一个账号。账号与阅读功能的现有许可、登录和缓存不受此开关影响。

采集 Flutter build/raster 帧耗时、按配置刷新率预算的慢帧与严重慢帧计数；刷新率不是动态硬件刷新率的精确测量，静止画面不报告假低 FPS。帧耗时使用最多 2048 个样本的有界抽样估算 P95。原生采集本进程内存、累计 CPU 时间、设备热状态、电量和供电状态，并附平台、系统、设备型号、版本与构建号。不可用项为 null，不用零值替代。Android 内存使用 PSS，iOS 使用 physical footprint，跨平台数值不能直接等同；内存均值/峰值来自采样。CPU 百分比以单核时间口径表示，可能超过 100%。

估算掉电率只使用至少 20 分钟、下降至少一个百分点的连续前台未接电片段。接电、切后台、读数异常或采样间隙打断片段。它是使用期间整机电量变化，不等于 APP 独占 mAh 或功率；不把前后台间隔归因给 APP。第一版不采集后台听书耗电、GPU 实时占用、完整操作链 trace 或系统其他 APP 的资源。

## 客户端与服务合同

- `lib/services/diagnostics/`：全局采集生命周期、本机有界汇总与待上传队列、原生资源桥。
- `ios/Runner/AppDelegate.swift` 和 `android/app/src/main/kotlin/com/niki/xxread/MainActivity.kt`：公开系统接口，`com.niki.xxread/diagnostics/getResourceSnapshot`。
- `lib/pages/support/`：主动反馈、诊断附件选择和开关。
- `lib/services/account/account_api_client.dart`：复用账号鉴权、令牌刷新与协议禁网边界；`POST /api/v1/support/feedback`、`POST /api/v1/support/diagnostics`。
- `lib/main.dart`：一个 Provider 拥有采集器，跟随账号许可和应用前后台状态。

每份摘要与反馈使用 UUID 幂等编号；成功后删除已接受待上传项，网络失败保留有界摘要供后续前台重试。反馈编辑/失败保留输入，用户明确附带时才提交性能摘要。后台严格校验固定字段及数值边界，不接受自由日志或任意 metadata。

后台侧边栏分开提供「用户反馈」和「性能统计」两个页面。前者查看分类、描述、版本及可选附件，标记新反馈/处理中/已解决；后者按平台、版本、构建号汇总。两页使用独立的数据请求、权限与错误状态。掉电率按总掉电百分点除以有效时长加权，显示有效样本数和时长。会话 P95 的加权均值不等于所有帧合并后的 P95。服务端能力、保留和权限见平台 `docs/support-diagnostics.md`。

自动摘要保留 30 天，反馈及附件保留 90 天，服务定期清理；注销账号级联删除关联在线记录。已上传资料不会因客户端关闭开关自动撤回。隐私正文唯一来源是平台 `app/legal/content.json`，本次隐私同意版本为 `2026-10-08.2`，同步包内快照而不覆盖历史修订。

iOS `ios/Runner/PrivacyInfo.xcprivacy` 为本功能声明账号关联、非跟踪的客户支持、性能数据、其他诊断及用户 ID 类型。诊断类型同时用于自动性能分析和用户主动反馈支持，分别列入 Analytics 与 App Functionality 用途。该声明与 Required Reason API、App Store Connect 隐私问卷分别维护；现有必要理由保留。此次交付是开发者直装，TestFlight/App Store 提交前还需同步问卷，并核对既有账号与云服务的数据类型，不能把本次窄修视为完整商店隐私审计。

## 验证与边界

授权弹窗回归为 `test/diagnostics_consent_dialog_test.dart` 和 `test/legal_startup_gate_test.dart`。回归入口为 `test/diagnostics_*`、`test/support_*`、`test/account_support_*`，以及平台 `tests/test_support*` 和隐私发布回归。验证账号切换、关闭开关、供电、采样缺失、前后台、重试及幂等，widget 文件独立进程执行。正常两端产品构建与服务上线分别验证，真机安装与物理反馈/长时电量验收不能互相代替。
