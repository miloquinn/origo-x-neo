# Website / GitHub 2.7.2 (260927003)

## Distribution contract

- Website/GitHub APKs, unsigned IPA, desktop packages and Flutter Web use `direct`.
  Read is free in this channel; Explore remains an Origo account entitlement.
- Website free Read does not create a paid cross-platform account entitlement.
  Existing Premium accounts retain Explore, including Read.
- The existing Explore purchase link opens the backend-configured
  `purchase_url` externally. Live config on September 27 returns
  `https://wzyp.cn/item/m3rfxi` (Liandong Shop). No duplicate hardcoded shop URL.
- Store apps continue to hide that external shop action. Play AAB is separately
  built with Google billing and store licensing for developer distribution.
- GitHub's unsigned IPA is now explicitly direct, while signed TestFlight/App
  Store builds retain `appleStore`. A direct IPA never receives sandbox Explore
  access; installation still requires the user's valid signing setup.
- Include the tested Explore profile card, redemption and localization changes
  from store build 260927002. The new website build is 260927003.
- Port the existing website macOS signing fix into this isolated release source:
  separate Developer ID entitlements and validate profile permissions before
  building/signing. Preserve unrelated dirty work in the main checkout.
