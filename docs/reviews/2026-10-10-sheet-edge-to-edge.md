# 2026-10-10 所有半屏菜单边到边验证

当前维护入口：[共用底部菜单](../bottom-sheets.md)。

## 问题与共享合同

旧共享外壳将底部安全区放在滚动 viewport 外。390×900、底部安全区 34、四边外间距 8 的用例中，面板底边为 892，viewport 底边为 866，中间有 26 点的矩形空白带，会提前截住阅读调节条。

`showGlassBottomSheet` 现默认边到边。外间距和连续圆角不变，剩余安全区放回内容的 MediaQuery，由滚动内容末端或固定页脚消费；键盘 viewInsets、左右刘海保护、原生拖动、泛型返回值及不可关闭导入事务保持各自合同。Route 的显式兼容 false 优先于子 Surface 的设置。

阅读设置同时保留原来的面板高度：上述用例面板仍为 476 点，viewport 从 406 增至 432 点，底边直接到达 892。滚至末尾后，最后一个控件仍停在 Home Indicator 上方。

## 全部入口审核

产品内 `showModalBottomSheet` 仅位于共享入口。以下消费者统一使用共享默认行为：

| 消费者 | 底部保护的位置 |
| --- | --- |
| 阅读设置、标题栏样式、翻页方式、点击区域 | ScrollView 内容末端 |
| 目录、书签、批注、漫画目录、搜索、朗读设置和章节 | 列表 bottom padding；朗读定时器的固定按钮内部 SafeArea |
| 字体、字号、玻璃外观、语言、登录方式、AI 阅读助手和选书 | ScrollView/ListView 内容末端 |
| 书库书籍操作、书籍信息、文件夹选择、整理与排序 | 滚动内容末端或固定确认/关闭页脚内部 |
| 书源分组、组织、去重和备份选择 | 滚动内容末端或固定操作页脚内部 |
| 书源切换章节、分类和 TXT 历史 | 未指定 padding 的 ListView 使用 Flutter 自带安全尾距 |
| 导入及调试的可拖动菜单 | 保留 DraggableScrollableSheet 原有控制器，安全区位于列表尾部 |
| 自定义配色选择器 | 固定按钮的内容 padding，键盘 viewInsets 单独保留 |
| AI 对话和段评 WebView | 沿用已经到底的 viewport 与既有输入区保护 |

静态短菜单由其内容内部 SafeArea 保护；固定页脚本身到达面板底边，正文止于页脚上方。没有把共享横条放进滚动区域。

## 回归入口

- `glass_bottom_sheet_edge_to_edge_test.dart`：默认滚动、默认固定页脚、显式旧合同及 route/Surface 设置优先级。
- `reader_settings_edge_to_edge_test.dart`：生产阅读设置的原面板高度、实际 viewport、末项点击及两类阅读子菜单。
- `bottom_sheet_consumers_edge_test.dart`：真实字体、窄屏大字字号、目录、书签及笔记，默认路由不传边到边 flag，验证末项完整可见和真实回调。
- 32 组独立 Flutter 测试共 320 个不同用例通过（其中书籍详情 22 项、共享二级页框架 7 项）。覆盖共享外壳、阅读、字体字号、外观、登录、AI、备份、书源组织/去重/切换、导入、漫画、TXT 历史及书库整理；未将多个有全局状态的 Widget 套件合并到一个进程。

共享默认模式的新增几何断言在旧布局上出现 26 点底部差值；路由优先级用例在 OR 合并设置时失败。修复后断言通过。定向静态分析覆盖父级 part library、生产组件、测试和预览入口。

组合交付另补验发现页的两条既有收藏/分组流程。390 点宽度下，带撤销操作的顶部 `SideToast` 会临时覆盖组织筛选；其中一条失败在打开任何底部菜单之前发生，相关提示布局也早于本次边到边迁移。测试现通过实际横向滑动关闭提示，再继续验证收藏、分组、筛选及撤销，保留全部原断言；两条用例在独立进程通过，没有修改产品提示或底部菜单行为。

## 原生证据与边界

`tool/preview_shared_glass_sheets.dart` 的 `ORIGO_SHEET_EDGE_PREVIEW=true` 分支渲染生产组件，覆盖液态浅色/暗色、毛玻璃、无玻璃、窄屏大字、横屏、阅读设置滚到末尾，以及字体、字号、目录、书签的真实末项。每个场景重建 Navigator，记录真实 viewport 和面板边界、末项安全余量及着色器就绪状态。

最终 11 个场景的液态着色器均已就绪，viewport 与面板底边的差值均为 0。5 个滚动末尾场景确认实际到达最大滚动位置；字体和字号末项到面板底边分别保留 46 点和 50 点的余量。场景及几何以 [原生渲染收据](../previews/sheet-edge-to-edge-20261010/render-context.json) 为准。媒体查询中的 Android 或特殊窗口参数属于显式布局模拟，不代表相应真机验收。正常滚动中内容可以延伸到圆角边缘，滑到末尾时操作项避开 Home Indicator；固定确认区则保留按钮内部的安全余量。

SloanePro 的签名构建、原地安装和启动由当前合并安装负责人从最终共享源码完成，保留已安装数据。模拟器预览不能代替用户对真机视觉、拖动和触感的验收。
