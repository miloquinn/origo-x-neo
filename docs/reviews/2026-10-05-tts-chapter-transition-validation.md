# 听书自动跨章节验证

截图反馈：一章听完后不加载下一章，需要关闭听书再刷新。

## 代码确认的问题与修复

- 听书原先直接调用正文缓存加载，绕过阅读页已有的章节失效恢复。现在共用一次目录刷新、章节映射和一次正文重试；登录、整本书失效等错误不触发章节恢复。
- 控制器原先在已知目录末尾直接停止。在线阅读器现在检查一次最新目录，按上一章的稳定 ID 或唯一规范化标题定位真正的下一章；确认没有下一章后正常停止，不循环刷新。
- 旧的跨章请求返回后可能停止刚开始的新播放。章节加载传递操作有效性检查，播放循环在停止前再次检查；重新打开同书时改用新页面的加载回调继续播放。
- 刷新目录后保留可见正文和原文位置。停止发生在新正文尚未返回时，保存进度按章节身份重新映射，避免目录插入导致保存到另一章。

## 修改范围与复用

- `lib/core/reader/reader_aloud_controller.dart`：加载有效性检查、允许在线目录末尾探测、保护迟到结果和同书重绑。未提供在线加载回调的本地书仍按原有章节边界结束。
- `lib/pages/reader/book_source/book_source_reader_chapter_loading.dart`：从原有阅读加载中提取共用恢复逻辑，复用 ID / 唯一标题映射。
- `lib/pages/reader/book_source/book_source_reader_aloud_actions.dart`：在线跨章加载、目录更新、进度映射。
- `lib/pages/reader/book_source/book_source_reader_settings.dart`：接入共用加载回调，删除重复正文转换。
- `test/reader_aloud_controller_test.dart`：目录末尾探测、迟到请求、同书重绑回归。
- `test/book_source_reader_aloud_transition_test.dart`：真实阅读页接线回归。

没有新增依赖。原有未提交修改保留；没有提交、推送、打包或发布。
