## 已复现的问题

1. 书源 `getArguments()` 仅在 JSON 解析失败时使用默认值。变量为合法空对象 `{}`、数组或旧版局部设置时，缺少服务器等字段，搜索地址变成 `undefined/search`；变量为 `null` 时会产生 JavaScript 错误。新导入、变量为 `''` 的原始规则能正确搜索，因此不能把用户设备上的所有搜索失败都归因于这个问题。
2. 关键词及来源直接拼进查询字符串，`&`、`+`、`#` 会改变关键词或截断请求。例如 `A&B` 被解析为标题 `A`，`A+B` 变为 `A B`。
3. 应用的 `source.setVariable()` 原先只保存于脚本运行时内存。重建 `SourceRuntime` 后，用户选择的服务器和搜索来源会丢失。该缺口已通过配置服务器、搜索、关闭运行时、重新创建并继续搜索的回归验证。
