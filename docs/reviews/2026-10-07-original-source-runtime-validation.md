# 原始书源与通用会话缓存验证

本次修复应用的通用书源运行时。用户提供的原始 JSON 不作修改，不增加书源名称或域名分支，不加入依赖。早先生成的适配副本不作为本次交付或通过依据。

## 已复现的接口缺口

原始脚本用 AES 加密登录信息，再调用 `cache.put("userInfo_" + source.getKey(), value)` 保存。旧实现的缓存只属于当前求值器，而且没有与 `source.getLoginInfo()`、原生登录表单和安全会话共享状态。登录接口成功后，脚本补充的登录密钥仍无法从持久会话读取；新增联网断言在旧实现下失败。

修复官方约定的 `sourceVariable_`、`userInfo_`、`loginHeader_`、`v_<sourceKey>_<name>` 缓存键与对应 `source` API 的一致性，补齐 `putVariable`、`removeLoginInfo` 及登录信息保存的布尔返回值。原生表单最新数据与明确清空的会话具有权威性。

普通脚本缓存复用现有安全会话和串行写入队列，保存绝对过期时间；内存缓存保持求值器生命周期。清空时沿用代次检查，阻止旧请求重新写回。过期回归同时覆盖运行时重建和单次脚本执行期间到期。
