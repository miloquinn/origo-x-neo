# 2026-10-10 主题图标覆盖与协议验证

当前维护指南见 [应用配色、素材主题与主题市场](../app-skins.md) 和 [随包素材目录](../app-skin-assets.md)。本文记录这次扩展的验证边界，不作为其他正在开发功能的交付证据。

## 结果与范围

语义图标从 16 槽扩展为 62 槽。公共按钮、菜单、搜索清除入口、设置标题与行项、书架操作、阅读控制/目录/搜索/设置/选择/注释工具，以及听书播放器和跟读入口接入同一 `AppSkinIcon` 解析器。只替换已知的图标叶子；原始皮肤、玻璃材质、动作、文字、点击区域和自定义品牌内容保持各自所有权。选中状态由真实控件状态传入，特殊翻页、下划线与对齐图标保持准确的原字形。

三套内置皮肤新增 552 张透明图标，补齐各槽的浅色、深色与选中状态；原有 198 张素材的像素文件未重写。共 750 张图片与 752 条 SHA-256 清单逐项验证，新增图形采用项目原创几何，原 IconPark 衍生素材保留来源与许可证。

v1 固定 16 槽和 96 个 ZIP 条目，v2 支持 62 槽和 512 个条目，槽位仍可选。双方保持压缩大小、展开大小、像素、路径和文件类型校验；目录条目也计入上限并验证安全性。安装收据和存储目录沿用原格式。公开 API 缺省 `maxSchemaVersion=1`，新官网和 App 显式请求 2，旧客户端不会收到不支持的主题。
