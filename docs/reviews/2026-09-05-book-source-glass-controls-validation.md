# 书源玻璃控件历史验证

本文从原 `2026-09-05` 计划文件保留独有的验证与视觉观察；文件日期沿用原记录，不重新认定每个观察的发生日期。实施清单已完成并移除，本文不是当前待办或安装授权。当前材质与所有权以 [共用玻璃材质](../glass-material.md) 为准。

## 历史观察与取舍

用户真机截图补充：超过20频道的分支仍用单列列表，改为响应式多列懒加载网格；更换按钮不再与标题平分宽度，靠右显示并复用玻璃胶囊；移除目录模式多叠加的12px空白及选择标题上方8px间距。返回目录复用已有行渐入/轻位移动效，滚动位置仍在内容透明时恢复。不得为动画复制整棵书单或一次性构建所有分类。

独立复审发现共用副页面按钮嵌在已模糊顶栏中会重复过滤；新增仅跳过模糊的选项，仍保留玻璃染色/描边。顶栏内按钮复用父级背景模糊，独立书源页按钮保留自身轻模糊。

## 验证结果

- 玻璃表面、胶囊、共享操作按钮、目录布局与架构共30项回归通过；包括关闭玻璃后的实体表面、单层模糊、30分类三列、500分类按需构建、大字体按钮右对齐。
- 发现页3项分别在独立进程通过：阅读频道不显示ORSP通用栏目、快速切换采用最新状态、返回目录保留滚动位置。返回测试还检查了过渡中间帧和目录行重新渐入，选择标题上方不再叠加多余间距。
- 命名清理涉及的导入、替换规则、HTML兼容和脚本测试通过；项目自有lib、test、tool、docs的内容和文件名扫描无禁用名称。
- 完整工作区 `dart analyze` 无问题，`git diff --check` 通过。独立只读复审通过，未发现新增实质问题。
- 删除顶部操作按钮重复样式，统一复用玻璃表面；超过20分类的单列分支已替换，未留下并行旧实现。未新增依赖。
- 尚未在用户手机上安装并检查触摸手感、动画帧率；自动化中间帧验证不等同于真机流畅度验收。

## 视觉验收

5个预览用例分别通过并逐张目视检查：阅读频道浅色、深色1.3倍字体、ORSP分类、30频道目录、选中频道书单。实际Flutter渲染中的30频道目录为三列胶囊，右侧空间得到利用；选中频道页的“更换”位于右端，标题顶部无额外叠加空白。玻璃按钮、选中态和深色文字可辨，阅读频道与ORSP栏目区分保持正确。截图位于 `.omx/book-source-ui-previews/glass-*.png`，使用模拟书源和共用样例封面，页面组件预览不包含完整手机导航外壳。
