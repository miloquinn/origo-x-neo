# Purchase visual assets

Approved direction: `docs/previews/purchase-editorial/index.html`.

Images are local-only decorative artwork; see ARTWORK-NOTICE.txt for CC0 sources. Phosphor.ttf is from https://raw.githubusercontent.com/phosphor-icons/web/master/src/regular/Phosphor.ttf and its glyph mapping from the adjacent style.css. MIT notice is bundled at assets/fonts/licenses/Phosphor-MIT.txt and visible in the app license screen. Const IconData mappings allow Flutter release icon tree shaking. No new package dependency or runtime asset download.

SHA-256 and exact original file sizes are recorded in manifest.json. Keep licenses/source records alongside any future replacement. Mock page fragments and sound bars are illustrative; real features and prices use separate localized, accessible widgets.
